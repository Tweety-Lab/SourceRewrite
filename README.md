# Source Formats ⚙️
*A Collection of C# Parsers for Valve/Source Engine File Formats.*

| **Format**     | **Supported** | **Notes**                               |
|:---------------|:--------------|:----------------------------------------|
| **MDL**        | ✔️            | Model format                            |
| **VTX**        | ✔️            | Mesh data                               |
| **VVD**        | ✔️            | Vertex data for models                  |
| **PHY**        | ✔️            | Model physics data                      |
| **VMF**        | ✔️            | Uncompiled map format                   |
| **VTF**        | ✔️            | Texture format                          |
| **KeyValues**  | ✔️            | Valve's JSON-like text format           |
| **GameInfo**   | ✔️            | `.txt` file with game information       |
| **VMT**        | ➖            | Material format (readable as KeyValues) |
| **BSP**        | ❌            | Compiled map format                     |
| **NAV**        | ❌            | AI navigation data                      |
